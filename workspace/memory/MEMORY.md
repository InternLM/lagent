**nanobot** - Ultra-lightweight personal AI assistant inspired by OpenClaw, 99% smaller codebase. Multi-channel support (Telegram, Discord, WhatsApp, WeChat, Feishu, etc.). Focus: production-ready, deployment, usability. **lagent** - Lightweight open-source framework for building LLM-based agents, PyTorch-inspired architecture. Modular design with components: actions, agents, llms, memory, prompts, hooks, services. Focus: flexibility, research, custom agent development. **Key Difference**: nanobot is an application (ready-to-use AI assistant), lagent is a framework (for building custom agents). nanobot has pre-built integrations, lagent has modular components. nanobot emphasizes deployment and usability, lagent emphasizes research and extensibility.
