# Workspace README

这是我的工作空间的 README 文件。

## 目录结构
- `AGENTS.md` - Agent 说明
- `HEARTBEAT.md` - 心跳任务配置
- `SOUL.md` - Agent 个人档案
- `TOOLS.md` - 工具说明
- `USER.md` - 用户档案
- `memory/` - 记忆系统
- `skills/` - 技能文件夹
- `README.md` - 本文件

## 使用说明
- 使用 `memory` 技能管理长时记忆
- 使用 `cron` 技能管理定时任务
- 使用 `clawhub` 技能安装新技能
- 使用 `github` 技能管理 GitHub 项目

## 技能列表
当前可用技能：
- cron - 定时任务
- memory - 记忆管理
- weather - 天气预报
- github - GitHub 集成
- clawhub - 技能仓库
- skill-creator - 创建技能
- summarize - 总结工具
- tmux - Tmux 集成

## 注意事项
- 请在使用前阅读相关技能的说明
- 重要信息已存储在 MEMORY.md 中
